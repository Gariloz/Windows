# 🛠️ Windows 10 Ghost Spectre Optimization

Набор скриптов и чек-лист для автоматизации настройки, очистки и оптимизации ОС **Windows 10 Ghost Spectre** сразу после установки. Запускать строго **от имени Администратора**.

---

## 🔌 Этап 1: Без интернета (Первая загрузка)

### 1. Подготовка и компоненты (Вручную)
- Отключить в Панели управления: `.NET 4.8`, `IE11`, `Print to PDF`, `XPS Writer`, `SMB Direct`, `Work Folders`.
- Удалить в Параметрах: `AV1/HEVC Extensions`, `Ножницы`, `Paint`, `CPU-Z`.

### 2. Цепочка автоматизации (`0. Automation`)
* **`CurrentDir.cmd`** — Динамический поиск папки `1.*` с защитой от пробелов.
* **`1. Temp.cmd`** — Перенос `TEMP` в `C:\Temp` с выдачей прав для всех профилей.
* **`2. Keyboard.cmd`** — Хоткей смены раскладки `Ctrl+Shift` для всех юзеров.
* **`3. Rebind Key.cmd`** — Переназначение клавиш через `Scancode Map`.
* **`4. Swap File...`** — Фиксация файла подкачки на 20 ГБ, включение анимации окон.
* **`5. Power CFG.cmd`** — Активация схемы питания `Game Turbo`.
* **`6. Services.cmd`** — Глушение служб обновлений, поиска и теневого копирования (`VSS`/`vmicvss`).
* **`7. Change Admin Path.cmd`** — Смена путей профиля в реестре под новое имя.
* **`8. Rename Admin...`** — Универсальное безопасное переименование учетной записи админа.
* **`9. Rename PC.cmd`** — Изменение сетевого имени компьютера.
* **`10. Restart Safe Boot.cmd`** — Перезагрузка ПК в безопасный режим с паузой.

### 3. Финал в Safe Mode
* **`11. Rename Administrator Folder.cmd`** — Физическое переименование папки пользователя (`Administrator` -> `Amnesia`), отключение Safe Mode и финальный ребут.

## 🌐 Этап 2: С интернетом

1. **`5. On Update.cmd`** — Включить Центр обновлений (нужно для winget).
2. **Язык** — Установить русский языковой пакет в параметрах Windows.
3. **Terminal** — Установить современную консоль:
   ```bash
   winget install -e --id Microsoft.WindowsTerminal
   ```
4. **Активация** — Активировать систему через MAS (HWID/KMS38).
5. **Драйверы** — Применить твики реестра, поставить драйверы чипсета и Visual C++ AIO.
6. **Ghost Toolbox / Driver Booster** — Установить DirectX и обновить недостающие устройства.
7. **NVIDIA** — Настроить режим максимальной производительности в панели видеокарты.
8. **`6. Off Update.cmd`** — Окончательно заблокировать Центр обновлений.
